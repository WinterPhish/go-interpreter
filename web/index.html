go-interpreter

An interpreter for Selenite, a small language written from scratch in Go. It reads your code, builds a tree from it, and runs it.

View on GitHub 3 stars 22 commits

Try it

Pick a program, run it, then pick a phase to see what each stage of the interpreter made of it. Everything stays in view side by side.

Example programs

Fibonacci

A function that calls itself to count up the sequence.

let fibonacci = fn(x) {
  if (x < 2) {
    return x;
  }
  fibonacci(x - 1) + fibonacci(x - 2);
};
fibonacci(15);

Factorial

Recursively multiply a number by each whole number below it.

let factorial = fn(n) {
  if (n == 0) {
    1
  } else {
    n * factorial(n - 1)
  }
};
factorial(6);

Closures

A function that builds another function and keeps hold of its own variable.

let newAdder = fn(x) {
  fn(y) { x + y };
};
let addTwo = newAdder(2);
addTwo(3);

Map

Apply a function to every item of an array, using only the built-ins.

let map = fn(arr, f) {
  let iter = fn(arr, accumulated) {
    if (len(arr) == 0) {
      accumulated
    } else {
      iter(rest(arr), push(accumulated, f(first(arr))));
    }
  };
  iter(arr, []);
};
let double = fn(x) { x * 2 };
map([1, 2, 3, 4], double);

Filter

Keep only the array items that pass a predicate function.

let filter = fn(arr, predicate) {
  let iter = fn(arr, accumulated) {
    if (len(arr) == 0) {
      accumulated
    } else {
      let item = first(arr);
      if (predicate(item)) {
        iter(rest(arr), push(accumulated, item));
      } else {
        iter(rest(arr), accumulated);
      };
    }
  };
  iter(arr, []);
};
let greaterThanThree = fn(x) { x > 3 };
filter([1, 2, 3, 4, 5, 6], greaterThanThree);

Hashes

Look up a value by its key, inside an array of hashes.

let people = [
  {"name": "Alice", "age": 24},
  {"name": "Anna", "age": 28}
];
people[0]["name"];

A macro

Code that rewrites code before it runs. This one swaps the two branches of an if.

let unless = macro(condition, consequence, alternative) {
  quote(if (!(unquote(condition))) {
    unquote(consequence);
  } else {
    unquote(alternative);
  });
};
unless(10 > 5, "not greater", "greater");

What Selenite can do

Functionslet add = fn(a, b) { a + b; };

First-class functions with closures and lexically scoped variables.

Collections[1, 2, 3, 4]

Arrays with indexing, and hashes keyed by integers, booleans or strings.

Macrosquote(8 + unquote(4 + 4))

Code that writes code, using quote, unquote and macro literals.

Strings"hi, " + "night"

Double-quoted text that you can join with the plus sign.

Built-inslen, first, rest, push, last

Five helper functions that are always available.

Errorstype mismatch: INTEGER + BOOLEAN

Mistakes come back as readable error objects.
