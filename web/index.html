go-interpreter

An interpreter for Selenite, a small language based on Monkey, written from scratch in Go. It reads your code, builds a tree from it, and runs it.

Examples

Five phases from text to answer

Each stage is its own Go package, and each one gives the next a fuller picture. The moon fills as the program takes shape.

lexer

Turns source into tokens: identifiers, keywords, operators, literals and delimiters.

parser

A hand-written Pratt parser. It reads tokens and respects operator precedence.

ast

The tree the parser builds. Every statement and expression becomes a node.

evaluator

Walks the tree and runs it: arithmetic, if expressions, closures, return and errors.

object

The values the language holds: integers, booleans, null, strings, arrays and hashes.

What Selenite can do

Functionslet add = fn(a, b) { a + b; };

First-class functions with closures and lexically scoped variables.

Collections[1, 2, 3, 4]

Arrays with indexing, and hashes keyed by integers, booleans or strings.

Macrosquote(8 + unquote(4 + 4))

Code that writes code, using quote, unquote and macro literals.

Strings"hi, " + "night"

Double-quoted text that you can join with the plus sign.

Built-inslen, first, rest, push, last

Five helper functions that are always available.

Errorstype mismatch: INTEGER + BOOLEAN

Mistakes come back as readable error objects.
